<interfaces>
From magnav/api.py (Plan 01). JS receives JSON strings and must JSON.parse them:
- backend_info(backend) -> str  keys: name, class, num_qubits, noise_model, is_ionq, python, platform, qiskit, numpy, scipy, sklearn, qiskit_ionq, data_file
- run_bell_batch(backend, n_circuits=2, shots=200) -> str
    ok: {ok: true, backend, n_circuits, shots, submit_to_result_s, ordering_ok, counts: [ {bitstring: count}, ... N ]}
    error: {ok: false, backend, n_circuits, shots, error_type, error}
- Allowed n_circuits: 2, 32, 64, 128. Allowed shots: 100, 200, 500, 1024, 4096.

Qollab JS runtime rules (RESEARCH.md Pattern 1): import Python by dotted name with a namespace import only; call with `.callPromising(...)` (a plain call fails on IonQ with an XHR ConnectionError); `backend` is injected, read with `typeof backend !== 'undefined' ? backend : (globalThis.backend ?? null)`; index.html is body-only and `<script>` tags do not run; main.css is the only stylesheet; one job per IonQ run.
</interfaces>
