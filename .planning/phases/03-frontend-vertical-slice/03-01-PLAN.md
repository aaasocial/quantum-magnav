<objective>
Build the Python side of Phase 3: a JSON-string API that hands the precomputed RunArtifact to JS (D-13) and a chunked, resumable live computation of one held-out line x one sensor (D-14) whose output has the exact shape and numbers of an artifact `lines[i]` entry (UI-01, UI-05).

Purpose: JS cannot fetch project files on Qollab (RESEARCH Open Question 1), and a single long Python call would freeze the page and could not be stopped at 90 s (Open Question 3). Chunking makes progress and the D-15 deadline possible. Reusing the pipeline's own helpers makes "identical visuals" in the fallback hold by construction.

Output: `magnav/live.py`, `tercom_steps` in `magnav/nav.py`, `line_entry` in `magnav/artifact.py`, per-line helpers in `magnav/pipeline.py`, six new `magnav/api.py` functions, and `tests/test_live.py`. No JS changes in this plan.
</objective>

New contracts this plan creates (consumed by Plans 02 and 04; the dev stub in Plan 02 mirrors them exactly):

- `api.artifact_json(backend) -> str`: `'{"ok":true,"artifact":<file text>}'` or `{"ok":false,"error_type":str,"error":str}`.
- `api.live_start(backend, line, sensor, simulate_failure=False) -> str`: `{"ok":true,"stage":1,"line":"1003.02","sensor":"mag_5_uc","windows_total":int,"order":["tl","raw","lowpass"]}`; simulate_failure truthy -> `{"ok":false,"stage":1,"error_type":"RuntimeError","error":"Simulated failure (demo of the fallback)"}`.
- `api.live_step(backend, budget_ms=250) -> str`: `{"ok":true,"stage":2|3,"fitting":"select"|"raw"|"lowpass"|"tl"|"quantum"|null,"fits_done":int,"fits_total":int,"denoiser":"tl"|"raw"|"lowpass"|null,"windows_done":int,"windows_total":int,"per_denoiser":{"tl":[done,total],...},"elapsed_s":float,"done":bool,"skipped":[...]}`.
- `api.live_skip(backend, denoiser) -> str`: allows only "raw" or "lowpass" before they finish; `{"ok":true,"skipped":[...]}`.
- `api.live_result(backend) -> str`: `{"ok":true,"line_id":str,"sensor":str,"computed":[...],"skipped":[...],"elapsed_s":float,"line":<artifact lines[i] entry for ONE sensor>}`. `line.estimates[sensor]` has keys for computed denoisers plus "quantum" (copied from tl while the stub equals TL); `line.metrics` has "dead_reckoning" and `[sensor][denoiser]`.
- `api.live_cancel(backend) -> str`: `{"ok":true}` always.
- Every failure: `{"ok":false,"stage":int|null,"error_type":str,"error":str[:2000]}`; nothing raises; all dumps use `allow_nan=False`.
